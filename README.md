## 🌟 Описание

Проект содержит набор инструментов для генерации текста с использованием архитектуры GPT-2:
- **Безусловная генерация** — создание текста "с нуля"
- **Интерактивный режим** — продолжение текста по промпту
- Поддержка стратегий:
  - `top-k` sampling
  - `top-p` (nucleus sampling)
  - Температурное сэмплирование

## 🚀 Быстрый старт

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите генерацию:
```bash
python generate_unconditional_samples.py --model_name 124M --nsamples 3
```

## ⚙️ Установка

### Требования
- Python 3.7+
- TensorFlow 1.x (`tensorflow==1.15`)
- Дополнительные пакеты:

### Подготовка моделей
1. Скачайте предобученные веса GPT-2
2. Создайте структуру:
```
models/
└── 124M/
    ├── encoder.json
    ├── hparams.json
    ├── model.ckpt.*
    └── vocab.bpe
```

## 📖 Использование

### Безусловная генерация
```bash
python generate_unconditional_samples.py \
  --model_name 124M \
  --length 200 \
  --temperature 0.8
```

### Интерактивный режим
```bash
python interactive_conditional_samples.py \
  --model_name 124M \
  --top_k 40 \
  --top_p 0.9
```

## 🎯 Параметры

| Параметр         | Тип     | Описание                          | По умолчанию |
|-------------------|---------|-----------------------------------|--------------|
| `--model_name`    | str     | Название модели (124M, 355M)     | 124M         |
| `--temperature`   | float   | Уровень случайности [0.1-1.0]    | 1.0          |
| `--top_k`         | int     | Ограничение по топ-k токенам     | 0            |
| `--top_p`         | float   | Nucleus sampling threshold       | 1.0          |
| `--length`        | int     | Длина генерируемого текста       | 1024         |
| `--batch_size`    | int     | Размер батча                     | 1            |
